# test-lt

基于 Flask 的 Web 项目。

## 快速开始

```bash
pip install -r requirements.txt
python run.py
```

访问 http://localhost:5000

## 项目结构

```
├── app/
│   ├── __init__.py      # 应用工厂
│   ├── routes.py        # 路由定义
│   ├── templates/       # HTML 模板
│   └── static/          # 静态资源
├── tests/               # 测试
├── requirements.txt
├── run.py               # 启动入口
└── README.md
```
